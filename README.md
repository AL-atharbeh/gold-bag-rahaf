# إدارة توزيع الذهب — نسخة تاجر الشنطة

تطبيق Flutter (أندرويد وآيفون، هاتف وتابلت) لتاجر شنطة ذهب في السوق الأردني:
يحمل الشنطة يومياً، يمرّ على المحلات فيبيع ويستلم كسراً ونقداً وشيكات،
ويتعامل مع التجار والمشاغل. الخادم Supabase (Postgres + RLS).

## ما في التطبيق

| التبويب | المحتوى |
|---|---|
| **الرئيسية** | ملخص اليوم (مبيعات، كسر، كاش، مصاريف، ربح)، الشنطة، الذمم، الشيكات، آخر الحركات |
| **الشنطة** | جرد كامل: البضاعة صنفاً صنفاً، الكسر، الكاش، الشيكات، مصاريف اليوم، إغلاق اليوم — والمشاغل ووارد البضاعة |
| **المحلات** | بيع من الشنطة (مع استلام كسر ونقد)، تسكير، قبض نقد أو شيك، مرتجع جزئي، كشف حساب |
| **التجار** | بيع وشراء ذهب أو كسر، تسكير، تسليم واستلام كسر، نقد وشيكات، فاتورة بضاعة |
| **الإعدادات** | التقارير، بيانات الترويسة، الذمم، الشيكات، الموظفون، الحسابات الثلاثة، اللغة |

- **يومية الشنطة:** فتح اليوم بتأكيد الكاش المحمول، وإغلاقه إلزامي بعدّ الكاش وتأكيد البضاعة والكسر.
- **التقارير (PDF بالعربية أو الإنجليزية):** كشف حساب لفترة يبدأ بالرصيد السابق، تقرير المبيعات، كشف الشنطة، جرد الشنطة، ذمم المحلات والتجار، سجل الشيكات، فاتورة كل حركة، يومية الشنطة.
- **التصحيح:** إلغاء حركة بقيد عكسي (لا حذف أبداً)، ومرتجع جزئي من فاتورة.
- **الدخول:** رقم هاتف وكلمة مرور فقط، بحد أقصى 3 حسابات تُنشأ من قاعدة البيانات — لا تسجيل من التطبيق.

## مبادئ المحاسبة

1. **دفتران لكل حساب — ذهب (ملغم صافي 24) ونقد (فلس)**، وكل حركة قيد مزدوج متوازن.
2. **لا `double`:** الأوزان بالملغم، المبالغ بالفلس، معاملات العيار بالـ ppm — كلها `int`.
3. **معامل العيار يُحفظ داخل كل سطر قيد**، فتعديل الجدول لاحقاً لا يغيّر الماضي.
4. **لا تعديل ولا حذف لحركة محفوظة** — قيد عكسي فقط.
5. الموجب في رصيد الطرف = لنا عليه، السالب = له علينا.

## البنية

```
lib/
  app/        المزوّدات (Riverpod) والسمة
  core/       الإعدادات، الوحدات، الهاتف، اللغة، الاتصال
  domain/     النماذج، الأنواع، LedgerBuilder (بناء القيود — قابل للاختبار وحده)
  data/       المستودع على Supabase
  platform/   الجلسة والمنشأة والفريق
  features/   الشاشات (الشنطة، المحلات، التجار، التقارير، PDF، …)
  l10n/       العربية والإنجليزية
supabase/
  migrations/ مخطط قاعدة البيانات مرتّباً 0001 → 0014
  tools/      تفريغ بيانات منشأة لإعادة الإدخال
test/         اختبارات المحاسبة والتقارير والشاشات
```

## التشغيل

### قاعدة البيانات (مرة واحدة لكل مشروع Supabase)
1. نفّذ ملفات `supabase/migrations` بالترتيب في SQL Editor.
2. Authentication → Sign In / Providers: فعّل Phone، وعطّل **Allow new users to sign up**.
3. أنشئ الحسابات (3 كحد أقصى) من SQL Editor:
   ```sql
   select edition_add_user('07XXXXXXXX', 'كلمة-مرور-قوية', 'الاسم', 'owner');
   select * from edition_users();
   ```

### التطبيق
```bash
flutter pub get
flutter run
```
عنوان المشروع ومفتاحه العام في `lib/core/config.dart`، ويمكن تمريرهما عند البناء:
`--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`
(المفتاح العام ليس سرّاً — الحماية في سياسات RLS.)

### نسخة أندرويد
```bash
flutter build apk --release
```
التوقيع من `android/key.properties` و`android/app/upload-keystore.jks` — **غير مرفوعين للمستودع**،
احفظهما بأمان: بدونهما لا يمكن إصدار تحديث فوق النسخة المثبّتة.

### الاختبارات
```bash
flutter test
```
