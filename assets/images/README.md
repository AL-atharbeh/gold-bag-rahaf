# الصور

ضع هنا صور التطبيق: الشعار، صور المنتجات، أي رسوم ثابتة.

الاستدعاء من الكود:

```dart
Image.asset('assets/images/logo.png')
```

ملاحظتان:

- أي ملف يُضاف هنا يُشحن تلقائياً — المجلد كله معلَن في `pubspec.yaml`،
  فلا حاجة لتعديل الإعدادات مع كل صورة جديدة.
- للشعارات والأيقونات، فضّل `.png` بخلفية شفافة أو `.svg`؛
  و`.webp` للصور الفوتوغرافية لأنها أخف بكثير من `.jpg`.
